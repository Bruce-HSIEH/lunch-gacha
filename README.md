# 台元午餐轉轉 🍙

竹北台元科技園區上班族的午餐扭蛋機。不知道中午吃什麼？轉一下就決定！

## 功能
- **隨機**：轉扭蛋機隨機抽一間（預設只抽竹北，新竹到「條件」打開），主畫面可直接用「今天預算」快速篩價位
- **條件**：地區（竹北市／新竹市）、車程（5／10／15／20 分）、料理類型、避開最近吃過
- **我的**：自己的口袋名單、最近吃過紀錄（存在手機瀏覽器裡）
- 「我不吃」：牛／豬／雞／羊／海鮮，主打該肉類的店自動跳過
- 151 間餐廳，每間店依招牌菜＋店名產生專屬可愛圖示
- 結果卡 Q 版小地圖：從通嘉科技（台元二街）出發的開車／走路時間估計
- 結果一鍵 Google 地圖導航
- 音效＋音樂盒背景音樂（Web Audio 即時合成），右上角可分別開關

## 使用
網址：https://bruce-hsieh.github.io/lunch-gacha/

用手機瀏覽器（Safari、Chrome 都可以）開啟頁面 → 分享 → 加入主畫面。步驟圖：`add-to-home-sop.png`

## 檔案
- `index.html`：整個 App（HTML + CSS + JS + 自製 SVG 圖示，單一檔案）
- `apple-touch-icon.png`：主畫面圖示

## 資料說明
店家清單寫在 `index.html` 的 `BASE` 陣列；車程為依區域估計，店家資訊可能變動。

## 改版流程
1. 修改 `index.html`
2. 更新 `index.html` 裡的 `APP_VERSION` 和 `CHANGELOG`
3. 把 `version.json` 改成同一個版本號（App 會用它檢查有沒有新版，自動更新）

## 注意事項（踩過的坑）
- iPhone 只在「加入主畫面」時讀啟動圖（`splash/`）和圖示；要換圖就**換檔名**（例如 `v1-` → `v2-`），並請使用者重新加入主畫面
- 開機畫面固定淺色：iOS 深色模式啟動會插一格白色（WebKit bug 311569）
- 開機畫面至少停 2.4 秒、最多 4 秒；更新說明等開機畫面結束後才跳
- 桌面 App 效能較低：動畫盡量用 transform／opacity，球停下來物理模擬就暫停，背景音樂用 `<audio>` 播預先渲染好的 WAV
